## Bugs found and fixed

1. Production build + CSP: Vite inlined the small woff2 fonts as data: URIs, which `font-src 'self'` blocks (fonts silently fell back). Fixed with `build.assetsInlineLimit: 0` in vite.config.ts; the e2e leak guard now fails on any CSP violation.
2. Sign out and account deletion bounced to `/login?next=/settings...`: the route guard was still mounted for one render after `logout()`. Guards now send a deliberate logout ('user' / 'account-deleted') to `/` (RouteGuards.tsx, 3 new unit tests).
3. DashboardPage.tsx contained a stray 0x85 byte (invalid UTF-8, a cp1252 ellipsis) in the loading skeleton's sr-only text: now a real ellipsis.
4. Dashboard list used a 30 s stale cache, so a drop burned by a recipient still showed under Active when switching filter tabs: the drops query now revalidates (staleTime 0).
