## Numbers

All on the i7-1195G7 laptop, Node 22.12, headless Chromium, Windows 11, local storage driver, API and Vite dev server on loopback.

- Argon2id derive in the browser (kdf worker, KDF_DEFAULT 64 MiB, t=3, p=1), 5 runs: 435, 342, 323, 320, 327 ms, median 327 ms. Command: `node _build/tmp/cipherdrop/i1/kdf-time.mjs` (Playwright `page.evaluate` of `kdfClient.deriveAccountKeys` on the dev server). Node smoke derive: 371 ms.
- Encrypt + upload of a 96 MB (100,663,296 B) random file as a signed-in user: 7,887 ms = 12.2 MB/s (24 chunks of 4 MiB, per-chunk SHA-256 and PUT, through the Vite dev proxy to the API, dev build). Command: `BIG_MB=96 node _build/tmp/cipherdrop/i1/run2.mjs`. The crypto package alone does ~864 MiB/s STREAM encrypt (C1 bench), so the upload is bound by the HTTP and storage path, not by crypto; measure again on `vite preview` in Phase P.
- Download + decrypt of the same 96 MB file in a fresh context, including page load: 27.8 MB/s (3,457 ms), and the SHA-256 of the saved file matched the original.
- Real flows: register incl. derive + account creation 934 ms; login 1.2 s; demo login in the UI 1.27 s.
- `npm run db:seed`: 9.1 s on a clean DB (two accounts at KDF_DEFAULT, one password drop, 4 drops, 1 report, 17 audit events). Second run creates nothing.
- `npm run smoke`: prelogin 123 ms, derive 371 ms, login 72 ms, vault unwrap 18 ms, `GET /me/drops` 22 ms, decrypt manifests 5 ms; prints all 4 seeded drops with decrypted names (4 of 4 manifests decrypted).
- Tests: crypto 147, shared 15, api 188 (+8 S3 tests skipped without `S3_TEST=1`), web 237 = 587 passing; `S3_TEST=1 npm run test:s3`: 24 passing against the compose MinIO.
- Requests carrying a plaintext file name or its URL-encoded form during the live flows (names with accents and a right-to-left override): 0.
